# FitBuddy – Demonstration Script

## Introduction
“FitBuddy is an AI fitness plan generator built with FastAPI, Google Gemini, SQLite, and Jinja2. It creates a 7-day general-wellness workout plan and can revise that plan using user feedback.”

## Demo 1 – User Profile
Enter:
- Name: Demo User
- User ID: demo001
- Age: 21
- Weight: 65 kg
- Goal: General Wellness
- Intensity: Medium

## Demo 2 – Generate Plan
Click the generate button and show the 7-day workout plan and nutrition/recovery tip.

## Demo 3 – Feedback
Submit feedback such as:
`Reduce high-impact exercises and add more recovery time.`

Show the revised plan.

## Demo 4 – Admin Dashboard
Open `/view-all-users` with the configured admin password and show stored users and plans.

## Demo 5 – API Documentation
Open `/docs` and show the available FastAPI documentation.

## Closing
“FitBuddy demonstrates a modular Generative AI application that combines user input, Gemini generation, database persistence, and feedback-based plan updates.”
