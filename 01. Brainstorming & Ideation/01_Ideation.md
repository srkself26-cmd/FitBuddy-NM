# FitBuddy – Brainstorming & Ideation

## Project Title
FitBuddy: AI Fitness Plan Generator

## Problem Statement
Creating a simple weekly fitness routine can be difficult when users have different goals, preferred intensity levels, ages, and available resources. FitBuddy is designed to provide a general-wellness fitness plan through a simple web application.

## Proposed Solution
FitBuddy uses Google Gemini through a FastAPI application to generate a personalized 7-day workout plan and a concise nutrition/recovery tip. Users can also submit feedback and request an updated plan.

## Target Users
- Beginners and general-wellness users
- People seeking a structured weekly routine
- Students demonstrating Generative AI application development

## Main Features
- 7-day workout plan generation
- Nutrition/recovery tip
- Feedback-based plan revision
- User and plan persistence with SQLite
- Admin dashboard
- FastAPI API and Swagger documentation

## Safety Scope
FitBuddy provides general wellness information. It is not a substitute for a doctor, dietitian, physiotherapist, or other qualified professional.
