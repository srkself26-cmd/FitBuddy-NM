# GitHub Upload Steps

1. Create a new GitHub repository.
2. Open a terminal in the `FitBuddy_Project` folder.
3. Run `git init`.
4. Run `git add .`.
5. Run `git commit -m "Initial FitBuddy submission"`.
6. Add your GitHub repository as the `origin` remote.
7. Run `git branch -M main`.
8. Run `git push -u origin main`.

## Important
Keep `.env` out of Git. The included `.env.example` contains only a placeholder for `GOOGLE_API_KEY`.
